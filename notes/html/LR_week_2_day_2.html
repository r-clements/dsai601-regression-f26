I. Sampling distributions

Start from the model:

yi= β0+ β1xi+ εi , i=1,…,n

Under the classical SLR assumptions:

yi∼N ( β0+β1xi ,σ2 )
β^0∼N ( β0, σ2 ( 1n+ x‾2SSX ) )
β^1∼N ( β1, σ2SSX )

where

SSX= ∑i (xi−x‾)2
Long description of Figure 7

The horizontal axis is the predictor x and the vertical axis the response y. Fourteen data points scatter upward from lower left to upper right. A straight line through the cloud, labelled y=β0+β1x, is the unknown population line. At one chosen x, a dashed vertical line rises from the axis to the point where it meets the line, and a bell-shaped curve is drawn on its side there, symmetric about the line. The picture is the statement yi∼N(β0+β1xi,σ2): the mean slides along the line as x changes, but the spread does not.

Long description of Figure 8

A thick solid line represents the true population regression line. Seven thinner lines are drawn over it, each one the least squares fit from a different hypothetical sample. Their slopes and intercepts differ, so they cross the population line at different angles, but the bundle is narrowest near the middle of the plot, where a tick on the horizontal axis is labelled x‾, and widest at the left and right extremes. This is the geometric content of the variance formula for a fitted value derived below: the term (xi−x‾)2SSX is zero at the mean of x and grows as you move away from it, so predictions are least certain far from the centre of the data.

Distribution of the fitted values

The fitted values are

y^i= β^0+ β^1xi

What is the distribution of y^i? It is normal, so we need only its mean and variance:

y^i∼N ( E(y^i) , Var(y^i) )

The mean

E(y^i) = E( β^0+ β^1xi ) = E(β^0) + E(β^1) xi = β0+ β1xi

The variance

Recall For two random variables,

Var(X+Y)= Var(X)+ Var(Y)+ 2Cov(X,Y)

But we don't need this. Instead, rewrite y^i as a single weighted sum of the responses, and the covariance term never appears.

Recall From last class, the slope is a linear combination of the responses:

β^1= ∑jkjyj
Var(y^i) = Var( β^0+ β^1xi ) = Var( y‾− β^1x‾+ β^1xi ) = Var( 1n ∑jyj + β^1 (xi−x‾) ) = Var( 1n ∑jyj + (xi−x‾) ∑jkjyj ) = Var( ∑j ( 1n+ (xi−x‾) kj ) yj ) = Var( ∑j k~jyj ) = ∑j Var(k~jyj)

Definition The combined weight in the line above is

k~j= 1n+ (xi−x‾) kj

Like kj, it is a constant, so it comes out of the variance squared.

Continuing:

= ∑j k~j2 Var(yj) = σ2 ∑j k~j2 ⋮ = σ2 ( 1n+ (xi−x‾)2 SSX )

Putting the mean and variance together:

y^i∼N ( β0+β1xi , σ2 ( 1n+ (xi−x‾)2 SSX ) )

Think about

  • What if xi=0?
  • What if xi=x‾?

II. Residuals

ei= yi− y^i

That is observed minus fitted (or expected).

Long description of Figure 9

The plot shows a straight fitted line rising from lower left to upper right, labelled y^=β^0+β^1x. Five observations are plotted; three sit above the line and two below it. From each observation a vertical segment runs to the line. An arrow drawn outward from the middle of one of those segments points to the label ei=yi−y^i, identifying the vertical segments as the residuals. The segments are vertical rather than perpendicular to the line, which is the visual reminder that least squares minimizes squared error in y only. Points above the line have positive residuals, points below have negative ones, and the sum of all of them is zero — the first property proved in the next section.

Difference between the errors and the residuals

The model error and the residual look similar but are not the same object:

εi= yi− β0− β1xi
ei= yi− y^i
Errors versus residuals: what is knowable
Quantity Built from Can we compute it?
εi (error) β0,β1 — the true parameters No — we don't know these
ei (residual) β^0,β^1 — the estimates Yes — we know these

The errors are assumed normal with constant variance:

εi∼N (0,σ2)

What is the distribution of ei?

ei∼N ( 0, σ2 ( 1− 1n− (xi−x‾)2 SSX ) )

Exercise How? The mean of 0 was flagged in the original notes as something to justify — work out why E(ei)=0.

Note the variance. Residuals are less variable than the errors they estimate: the subtracted terms shrink σ2. Fitting two coefficients uses up some of the variability in the data.

III. Properties of the fitted values and residuals

1. The residuals sum to zero

∑iei=0

Recall that ∂Q∂β0=0 at the least squares solution:

∂∂β0 ∑i (yi−β0−β1xi)2 = −2 ∑i (yi−β0−β1xi) =0 ∑i (yi−β^0−β^1xi) = 0 ∑i (yi−y^i) = ∑iei = 0

The factor of −2 was cancelled in the original notes, since the whole expression is set to zero.

2. The fitted values and the observations have the same total

∑iyi = ∑iy^i

Rearranging the definition of a residual, y^i=yi−ei, and summing:

∑iy^i = ∑iyi − ∑iei

and the second sum is 0 by property 1.

3. The residual sum of squares is the global minimum of Q

∑iei2 is the global minimum of Q(β0,β1), where

Q(β0,β1) = ∑i (yi−β0−β1xi)2
Long description of Figure 10

A perspective sketch with three axes meeting at one corner: Q pointing up, β0 pointing right, and β1 pointing up-left into the page. Above the plane of the two coefficients floats a bowl, drawn as an outer rim ellipse, two smaller contour ellipses inside it, and a U-shaped profile — the surface Q(β0,β1). A dot marks the bottom of the bowl. A solid vertical line drops from that dot to the coefficient plane, marking the pair (β^0,β^1), and a dashed line runs from the same dot across to the Q axis, where a mark is labelled ∑iei2. Because the surface is a bowl rather than a saddle, the stationary point found by setting both partial derivatives to zero is a genuine global minimum, and its height is the residual sum of squares.

4. The residuals are orthogonal to the predictor

∑ieixi =0

This holds because ∂Q∂β1=0 at (β^0,β^1):

−2 ∑i (yi−β0−β1xi) xi =0

5. The residuals are orthogonal to the fitted values

∑ieiy^i =0
∑iei (β^0+β^1xi) = ∑ieiβ^0 + ∑ieiβ^1xi = β^0 ∑iei + β^1 ∑ieixi

Both sums are 0 — the first by property 1, the second by property 4 — so the whole expression is 0.

IV. An estimator for the error variance

With the model yi=β0+β1xi+εi and εi∼N(0,σ2), let's find an unbiased estimator σ^2 — one with

E(σ^2) =σ2

Given to you

∑iei2 σ2 ∼ χn−p2

where p is the number of β's in the model. For SLR, p=2.

Long description of Figure 11

The horizontal axis is v, the value taken by a chi-squared random variable, and the vertical axis is its density f(v). The curve starts at the origin, climbs steeply to a peak in the left third of the plot, then decays slowly, staying above the axis far to the right. The asymmetry matters: unlike the normal distributions used for the coefficients, this distribution lives only on non-negative values, which is what you want for a sum of squares.

The building block is a sum of squared standard normals:

V= ∑i=1n zi2 ∼ χn2 , zi∼N(0,1)
Properties of a chi-squared random variable with n degrees of freedom
QuantityValue
E(V) n
Var(V) 2n

For SLR, with p=2:

V= ∑iei2 σ2 ∼ χn−22

So its expected value is n−2, and we can solve for σ2:

E ( ∑iei2 σ2 ) = n−2 1σ2 E (∑iei2) = n−2 1n−2 E (∑iei2) = σ2 E ( ∑iei2 n−2 ) = σ2

The quantity inside that last expectation is our estimator:

σ^2 = ∑iei2 n−2

This is the mean squared error (MSE).

Note The MLE for σ2 is biased,

∑iei2 n

but it maximizes the likelihood. Dividing by n−2 instead of n is what buys unbiasedness.

V. Hypothesis testing for SLR

Say we want to test specific values of the slope. We know

β^1∼N ( β1, σ2SSX )

The hypothesis testing framework has five steps:

  1. Hypotheses
  2. Test statistic
  3. Choose α
  4. Find cutoff
  5. Make decision

1. Hypotheses

H0 : β1=β1* H1 : β1≠β1*

2. Test statistic

Standard error. For any estimator,

SE(θ^) = Var(θ^)
Z = β^1−β1* SE(β^1) = β^1−β1* σ2SSX = β^1−β1* σSSX ∼ N(0,1)

But σ is unknown, so use the estimated standard error

SE^(β^1) = σ^SSX

which changes the reference distribution from normal to t:

t= β^1−β1* σ^SSX ∼ tn−2

3 and 4. Choose α and find the cutoff

Long description of Figure 12

A symmetric bell-shaped density for the t distribution with n−2 degrees of freedom sits over a horizontal axis whose centre is marked 0. Two vertical lines, placed symmetrically either side of centre, divide the area under the curve into three parts: a small tail on the left, a small tail on the right, and the bulk in the middle. Leader lines point to each tail, labelling both α/2, and the central region is labelled 1−α. The position of the right-hand line on the axis is labelled t1−α/2,n−2*. Because the test is two-sided, the chosen error rate α is split evenly between the two tails, which is why the cutoff is indexed by 1−α/2 rather than 1−α.

5. Make the decision

|t| > t1−α/2,n−2*

If that holds, reject H0: there is enough evidence to suggest β^1≠β1*.

Note Usually we use H0:β1=0. In this case, if we reject H0 we say "x is a significant predictor of y."

Testing the intercept

H0 : β0=β0* H1 : β0≠β0*
t= β^0−β0* σ^ 1n+ x‾SSX

Transcription note The denominator above is copied exactly as written on page 10 of the handwritten notes, with x‾SSX. Every other appearance of this standard error — the sampling distribution of β^0 earlier in these notes, and the confidence interval below — carries x‾2SSX. The squared version is the one consistent with Var(β^0); treat the unsquared form here as a slip of the pen.

Confidence intervals

The general shape of a confidence interval:

estimate ± statistic × SE(estimate)

where the statistic is the number of standard errors you reach out on either side. For the two coefficients:

β^1 ± t1−α/2,n−2* σ^SSX
β^0 ± t1−α/2,n−2* σ^ 1n+ x‾2SSX

Why the interval works

Start from the pivotal quantity — note that this uses the true β1, not a hypothesized value:

β^1−β1 SE^(β^1) ∼ tn−2
Long description of Figure 13

The same symmetric t density as before, but now both cutoffs are named on the axis: the left one tα/2,n−2* and the right one t1−α/2,n−2*. Each tail beyond a cutoff holds area α/2 and the region between them holds 1−α. Whereas Figure 12 used this picture to place a rejection boundary for a test, here the same picture is a probability statement about the pivotal quantity, which is then algebraically rearranged so that the unknown parameter — not the statistic — sits in the middle of the inequality.

By construction, the probability of landing between the two cutoffs is 1−α:

P ( tα/2,n−2* <t< t1−α/2,n−2* ) =1−α

Substitute the pivotal quantity for t:

P ( tα/2,n−2* < β^1−β1 SE^(β^1) < t1−α/2,n−2* ) =1−α

Rearranging so that β1 sits alone in the middle:

P ( β^1 + tα/2,n−2* SE^(β^1) < β1 < β^1 + t1−α/2,n−2* SE^(β^1) ) =1−α

Symmetry The lower cutoff is just the negative of the upper one:

tα/2,n−2* =− t1−α/2,n−2*

which turns the statement into the familiar symmetric form:

P ( β^1 − t1−α/2,n−2* SE^(β^1) < β1 < β^1 + t1−α/2,n−2* SE^(β^1) ) =1−α

This is the confidence interval form. The probability that the true β1 is in the interval is 1−α.
