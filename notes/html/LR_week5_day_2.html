I. Categorical predictors

A K-level categorical predictor becomes K−1 dummy variables.

Insurance data, regressing price on region:

region={ NE, NW, SE, SW }

so K=4 and region contributes three columns, not four. This is one-hot encoding:

The design matrix X. The final column is not part of X; it names the level each row encodes, which the original notes marked with highlighter.
Intercept NW SE SW Region this row encodes
1000NE — reference category
1100NW

Northeast (NE) is called the reference category. It has no column of its own — a row of zeros across NW, SE and SW is the NE encoding.

y^= β^0+ β^1NW+ β^2SE+ β^3SW

Worked example — an NW observation. Substitute NW=1, SE=0, SW=0, and everything but β^0+β^1 switches off.

β^0 = mean price for NE.

Fitted value for each region

Every region's fitted value, and what those come to at β^0=50k, β^1=5k
Region y^ Numeric value
NE β^0 50k
NW β^0+β^1 55k
SE β^0+β^2 —
SW β^0+β^3 —

The notes give values only for β^0 and β^1, so the last two rows have no number attached.

So β^j = difference in mean of Y between category j and the reference category (β^0).

Ordinal categorical

y^= β^0+ β^1educ.

Example — education level coded as a single numeric column:

An ordinal predictor squeezed into one column
Level Some HS HS AA BA MA PhD
Code 123456

Caution This implies there's a distance between categories — that the step from Some HS to HS is the same size as the step from MA to PhD, and that PhD is six times Some HS.

II. Interactions

Does the effect of X1 on Y depend on the value of X2?

Example: does the effect of age on price depend on region?

Categorical + continuous

y^= β^0+ β^1Age+ β^2Smoker+ β^3Age×Smoker

That last term is the interaction. Smoker is coded No = 0, Yes = 1.

When Smoker = No = 0, the last two terms vanish:

y^= β^0+ β^1Age

Otherwise (Smoker = Yes = 1), collect the constant terms and the Age terms separately:

y^ = β^0+ β^1Age+ β^2+ β^3Age = (β^0+β^2) + (β^1+β^3) Age

The original highlights the two bracketed pieces in different colours. Here they are separate columns — the point is that the interaction changes both:

Different slopes, different intercepts
Smoker Intercept Slope on Age
No (0) β^0 β^1
Yes (1) β^0+β^2 β^1+β^3
Long description of Figure 29

Axes with age on the horizontal and price on the vertical. Two straight lines are drawn. The solid line, labelled "Smoker", meets the vertical axis at the higher of the two intercepts, marked β^0+β^2, and climbs steeply across the plot. The dashed line, labelled "Non-smoker", meets the axis lower down at β^0 and rises only gently.

The two things to read off the picture: the lines start at different heights, which is the β^2 term, and they climb at different rates, which is the β^3 interaction term. Drop the interaction and the lines would be forced parallel — the group difference would be the same at every age. Because they are not parallel, the vertical gap between them grows with age: smoking costs more at 60 than it does at 20. Solid versus dashed carries the same distinction as the two pen colours in the original.

Continuous + continuous

y^= β^0+ β^1Age+ β^2Income+ β^3Age×Income

Collecting the Age terms:

( β^1+ β^3Income ) Age

The slope on Age is now a function of income — not one number but a different number at every income level.

Categorical + categorical

y^= β^0+ β^1Smoker+ β^2Alcohol+ β^3Smoker×Alcohol
Fitted value in each of the four cells
Alcohol \ Smoker No (0) Yes (1)
No (0) β^0 β^0+β^1
Yes (1) β^0+β^2 β^0+β^2+β^1+β^3

The additional effect of smoking. The original braces the β^1 in the top-right cell and the β^1+β^3 in the bottom-right and labels both "additional effect of smoking". Among non-drinkers smoking adds β^1; among drinkers it adds β^1+β^3. The gap between those two is exactly β^3.

The main-effects rule

Note: if X1×X2 is in the model, include the main effects X1 and X2.

The rule applies all the way down. A three-way interaction drags in everything beneath it:

What X1×X2×X3 requires
OrderTerms that must be in the model
Main effects X1,X2,X3
Two-way X1X2,X1X3,X2X3
Three-way X1X2X3

III. Centering and standardizing

① Centering

Xi− X‾i

Worked on income, with mean income = 50:

Centering shifts the origin to the mean; spacing between values is untouched
Income Incomec
50k0k
60k10k
62k12k
⋮⋮

Do this for interactions. After centering,

β^j= “effect of Xj at average value of Xj+1”

Without centering, the coefficient on Xj in a model with an interaction describes the effect when the other variable is zero — which is often a value that never occurs in the data.

② Standardizing

Z= Xj−X‾j sd(Xj)
  • Puts all Xs on the same scale.
  • Each value becomes the number of standard deviations from the mean.

Interpretation: “for each 1-sd increase, y changes by β.”
