Simple linear regression (SLR)

Simple linear regression uses one predictor (x) and one response (y).

Vocabulary: the two variables go by several names
SymbolNames used for it
xpredictor, independent variable, covariate, feature
yresponse, dependent variable, target

Example data

A running example: predicting the weight of a frog from its length.

The SLR model

yi = β0 + β1 xi + εi , i=1,…,n

Each symbol, and whether it is a fixed (non-random) quantity or a random one:

Components of the simple linear regression model
Symbol Meaning Fixed or random?
yi ith observation of the response y Random
xi ith observation of the predictor x Fixed
n sample size Fixed
β0 unknown intercept parameter Fixed
β1 unknown slope parameter Fixed
εi random error term Random

The key idea. The parameters β0 and β1 are fixed but unknown. Randomness enters only through εi, and that randomness is what makes yi random.

Population line vs. estimated line

Long description of Figure 1

The horizontal axis is x, the predictor. The vertical axis is y, the response. Twelve data points scatter upward from left to right. Two straight lines are drawn through the cloud of points and are close to each other but not identical:

  • A solid line is the population regression line, y=β0+β1x. It is unknown.
  • A dashed line is the estimated line, y^=β^0+β^1x. It is computed from the sample.

The takeaway is that the estimated line approximates, but does not exactly reproduce, the population line.

Distribution of the errors

Long description of Figure 2

A straight regression line y=β0+β1x rises from lower left to upper right. At two separate values of x, a sideways bell curve is drawn, centred on the line and spanning a vertical band of equal height at both locations. The equal width of the two curves illustrates the constant-variance assumption: the spread of εi is the same everywhere along the line, and the curves are centred on the line because the errors have mean zero.

Model assumptions

What "simple" and "linear" mean

  1. Simple: there is exactly one predictor, x.
  2. Linear: yi is a linear function of β0 and β1 — linear in the parameters, not necessarily in x.

Assumptions on the errors

Basic assumptions — the errors εi are random variables satisfying:

  1. Mean zero. E(εi)=0
  2. Constant variance (homoscedasticity). Var(εi)=σ2 — the same σ2 for every observation.
  3. Uncorrelated errors. Cov(εi,εj)=0,i≠j

Classical (additional) assumption — useful for inference:

  1. Normality. εi∼N(0,σ2)

Assumptions (i)–(iii) are enough to get the least squares estimates and their variances. Assumption (iv) is what lets you build confidence intervals and run hypothesis tests.

The regression function

The regression function is the conditional mean of the response given the predictor:

g(x) = E(y∣X=x) = β0+β1x

Estimating the coefficients: least squares

We need to estimate β0 and β1. How? Use the least squares principle.

Long description of Figure 3

A straight line rises from lower left to upper right through a set of five data points. Each point is connected to the line by a short vertical segment. Some points sit above the line and some below. These vertical gaps are the quantities we try to make small; least squares makes the sum of their squares as small as possible.

Minimise the sum of squared errors:

Q(β0,β1) = ∑i=1n εi2 = ∑i=1n (yi−(β0+β1xi)) 2
Long description of Figure 4

Three axes are drawn: Q vertically, β0 horizontally to the right, and β1 receding diagonally into the page. Above the plane sits a bowl-shaped surface (a paraboloid) that opens upward, shown as a parabola with a few nested elliptical contour rings. The bottom of the bowl is a single point. Dashed lines drop from that point to the β0 and β1 axes, marking the coefficient values that minimise Q. Because the surface is convex, setting both partial derivatives to zero locates the unique minimum.

Setting the partial derivatives to zero

At the minimum, both partial derivatives vanish:

∂Q∂β0 =0 ∂Q∂β1 =0

Derivative with respect to the intercept

∂Q∂β0 = ∂∂β0 ∑i=1n (yi−β0−β1xi)2 = ∑i=1n ∂∂β0 (yi−β0−β1xi)2 = ∑i=1n 2 (yi−β0−β1xi) (0−1−0) = −2 ∑i=1n (yi−β0−β1xi) =0

The third line is the chain rule: differentiate the square, then multiply by the derivative of the inside, which is −1.

Derivative with respect to the slope

∂Q∂β1 = ∑i=1n ∂∂β1 (yi−β0−β1xi)2 = ∑i=1n 2 (yi−β0−β1xi) · (0−0−xi) = −2 ∑i=1n (yi−β0−β1xi) xi =0

Solving for the estimates

Solving the intercept equation

Start from the first normal equation and use y‾=1n∑yi:

−2 ∑i=1n (yi−β0−β1xi) = 0 ∑i=1nyi − ∑i=1nβ0 − ∑i=1nβ1xi = 0 ny‾ −nβ0 −nβ1x‾ = 0 y‾−β1x‾ = β0

Solving the slope equation

Substitute β0=y‾−β1x‾ into the second normal equation and collect terms:

∑i=1nyixi −β0 ∑i=1nxi −β1 ∑i=1nxi2 =0 ∑i=1nyixi − (y‾−β1x‾) ∑i=1nxi −β1 ∑i=1nxi2 =0 ∑i=1nxiyi −ny‾x‾ +nβ1x‾2 −β1 ∑i=1nxi2 =0 ∑i=1nxiyi −ny‾x‾ = β1 ( ∑i=1nxi2 −nx‾2 )

The least squares estimators

β^1 = ∑i=1nxiyi −ny‾x‾ ∑i=1nxi2 −nx‾2
β^0 = y‾ − β^1 x‾

Note. Estimate the slope first, then plug it into the intercept formula. Because β^0=y‾−β^1x‾, the fitted line always passes through the point of means (x‾,y‾).
