Where this is heading

Before building it up, here is the destination. Collect the responses into a vector, the predictors into a matrix, and the coefficients into a vector:

Y= ( y1 ⋮ yn ) β^= ( β^0 β^1 ⋮ β^p−1 )

and the whole least squares problem collapses to a single formula:

β^= (XTX)−1 XTY

II. Matrix-vector notation

Start by stacking the n equations of the SLR model:

( y1=β0+β1x1+ε1 y2=β0+β1x2+ε2 ⋮ yn=β0+β1xn+εn )

Those n lines are exactly one matrix equation. Define:

The four objects, and their dimensions, for simple linear regression
Object Contents Dimensions
Y the responses y1,…,yn n×1
β the coefficients β0,β1 2×1
X a column of 1's, then the predictor x1,…,xn n×2
ε the errors ε1,…,εn n×1

The column of ones is what carries the intercept. Multiplying it by β0 adds the same constant to every row, which is precisely what an intercept does.

Y= Xβ+ε Y^= Xβ^ e= Y−Y^=Y−Xβ^

Assumptions, and random vectors

  1. X is fixed.
  2. ε∼N(0,σ2In×n)

Writing out that covariance matrix makes the two old assumptions visible at once:

( σ20⋯ 0⋱0 ⋯0σ2 ) = σ2I

Read the matrix The σ2's down the diagonal are constant variance. The zeros off the diagonal are uncorrelated errors, Cov(εi,εj)=0. Both assumptions now live in one object.

Mean vector and covariance matrix

For a random vector Z=(Z1,Z2):

E(Z)= ( E(Z1) E(Z2) ) =μ
Var(Z)= ( Var(Z1) Cov(Z1,Z2) Cov(Z2,Z1) Var(Z2) ) =Σ

the covariance matrix. The definition of variance carries over from the scalar case by replacing the square with an outer product:

Variance for a random variable versus a random vector
CaseDefinition
Random variable Z Var(Z)=E[(Z−μ)2]
Random vector Z Var(Z)=E[(Z−μ)(Z−μ)T]

Check the shapes In the vector case (Z−μ) is n×1 and its transpose is 1×n, so the product is n×n — a whole matrix, not a single number.

The multivariate normal distribution

Middle panel. Looking straight down at that surface, the level curves are concentric circles centred at the origin. This is the case Σ=σ2I: equal variance in every direction and no correlation, which is exactly what our error assumption asserts.

III. Multiple regression

In SLR we minimized

Q(β0,β1) = ∑i=1n (yi−β0−β1xi⏟this is ŷᵢ)2

New notation A sum of squares is an inner product:

∑iai2 = aTa for a= ( a1 ⋮ an )

So the criterion becomes a single expression in the vector β:

Q(β) = (Y−Xβ)T(Y−Xβ) = ‖Y−Xβ‖22

the 2-norm squared.

Matrix calculus rules

To minimize Q(β) when β is a vector, we need three derivative rules:

Derivatives with respect to a vector
ExpressionDerivativeCondition
∂(βTA)∂β A —
∂(βTAβ)∂β 2Aβ if A is symmetric
∂c∂β 0 c is constant

Minimizing Q(β)

Expand the criterion:

Q(β) = (Y−Xβ)T(Y−Xβ) = YTY −YTXβ −(Xβ)TY +(Xβ)T(Xβ) = YTY −YTXβ −βTXTY +βTXTXβ

Why the third term simplifies (Xβ)TY=βTXTY, because transposing a product reverses the order.

Now differentiate and set to zero:

∂Q∂β = 0 −XTY −XTY +2XTXβ = −2XTY +2XTXβ =0

The factors of 2 cancel, leaving the normal equations:

XTXβ = XTY β^ = (XTX)−1 XTY

Adding more predictors

Nothing above used the fact that X had only two columns. So we can simply add more:

yi= β0+ β1x1i+ β2x2i+ ⋯+ βp−1x(p−1)i+ εi , i=1,…,n

Why the last coefficient is βp−1 Because p counts the number of coefficients, not the number of predictors. Indexing from β0 means the last one is βp−1, and there are p−1 actual predictors plus the intercept.

The model is still Y=Xβ+ε, with

X= ( 1x11x21⋯x(p−1)1 1x12x22⋮ ⋮⋮⋮⋱ 1x1nx2n⋯x(p−1)n ) β= ( β0 β1 ⋮ βp−1 )

X is called the design matrix, and β is p×1.

Full rank The formula β^=(XTX)−1XTY assumes X has full rank — that the columns of X are linearly independent. Otherwise XTX is not invertible and there is no unique solution.

The hat matrix

Y^= Xβ^= X (XTX)−1 XT ⏟ H Y =HY

H is the hat matrix — it puts the hat on Y. The residuals then have an equally compact form:

e= Y−Y^= Y−HY= (I−H)Y

The geometry of least squares

Long description of Figure 23

A slanted parallelogram drawn in perspective represents the column space of X — every vector you could possibly build as Xβ for some choice of β. It is p-dimensional, and two axes labelled x1 and x2 are drawn inside it as the columns that span it.

From the origin, a long vector Y points up and out of the plane: the observed responses live in n-dimensional space and, in general, do not lie in the plane. A shorter vector Y^=Xβ^ lies flat inside the plane. A dashed segment runs from the tip of Y^ up to the tip of Y; it is labelled e=Y−Y^, and a small square marks the right angle where it meets the plane.

This is the whole content of least squares in one image. Minimizing ‖Y−Xβ‖22 means finding the point of the plane closest to Y, and the closest point is the foot of the perpendicular. The residual vector lives in the orthogonal complement, which has dimension n−p — the source of the degrees of freedom in σ^2.

IV. Distributions of the estimates

Transcription note The handwritten notes label this section VI, jumping straight from III. It is renumbered IV here so the sections run in sequence.

First, a general fact about linear transformations of a random vector. If W∼N(μ,Σ) and A is a constant matrix, then:

Linear transformation of a normal random vector
QuantityResult
E(AW) Aμ
Var(AW) AVar(W)AT=AΣAT
AW N(Aμ,AΣAT)

1. The response vector

Y∼N (Xβ,σ2In×n)

2. The coefficient vector

Apply the rule with A=(XTX)−1XT, so that β^=AY:

β^ ∼ N( (XTX)−1XTXβ , (XTX)−1XT σ2I [(XTX)−1XT]T ) = N( β, σ2 (XTX)−1XTX [(XTX)−1]T ) = N( β, σ2 [(XTX)−1]T ) = N( β, σ2 (XTX)−1 )

The last step uses (XTX)T=XTX — that XTX is symmetric.

Why transpose and inverse commute

AA−1=I (AA−1)T=I (A−1)TAT=I (A−1)TAT(AT)−1=I(AT)−1 (A−1)T=(AT)−1

Compare with SLR. The single formula β^∼N(β,σ2(XTX)−1) contains every result from Week 2: the diagonal entries of σ2(XTX)−1 are the variances Var(β^0) and Var(β^1) we derived by hand, and the off-diagonal entry is Cov(β^0,β^1).
